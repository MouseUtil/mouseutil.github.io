MouseUtil / Features

Features

Windows 10/11 · Free & open source

Two main modes

Auto click

Automatically clicks where the mouse pointer currently is on the screen.

Jiggle

Moves the cursor in a tiny circle and lands back on the exact starting pixel.

Automation & timing

Custom interval

Set the timer between each click or jiggle.

Randomized interval

Enable for a more "authentic" presence. Your custom interval becomes the cap.

Interval display

Switch between a Minutes/Seconds display or full Hours/Minutes/Seconds/Milliseconds.

Auto start

Start automation in your preferred mode right as the app launches.

Pause on manual movement

Touch the mouse yourself and the utility pauses for you.

Auto-stop conditions

Set a click/jiggle repeat limit or a stop date and time.

Global hotkey

Start or stop from anywhere with one keypress or key combination. F6 by default.

Status & feedback

System tray support

Can run in system tray with icon states, live tooltip, and a menu to start or stop the utility.

Live status & progress

A live countdown to the next click or jiggle, along with a total counter.

Taskbar icon progress

A progress bar on the taskbar icon that gradually depletes until the next click/jiggle.

Fits right into Windows

Launch on startup

Launch MouseUtil automatically when Windows starts.

Fluent design

Build with WinUI with support for light, dark, or automatic theming.

Persisted config file

Your interval, hotkey, and all other settings are remembered the next time you open the app.
