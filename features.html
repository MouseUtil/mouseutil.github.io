MouseUtil / Features

Features

Windows 10/11 · Free & open source

Two main modes

Auto click

Automatically clicks where the mouse pointer currently is on the screen.

Spin mode

Moves the cursor in a tiny circle and lands back on the exact starting pixel.

Set your own interval

Custom interval

Set the timer between each click or spin.

Randomized interval

Enable for a more "authentic" presence. Your custom interval becomes the cap.

Advanced interval view

Enable a more precise interval display with Hours / Minutes / Seconds / Milliseconds.

Stays out of your way

Pause on manual movement

Touch the mouse yourself in Spin Mode and the utility pauses for you.

Auto-stop conditions

Set a click/spin repeat limit or a stop date and time.

Global hotkey

Start or stop from anywhere with one keypress. F6 by default.

See what it's doing

System tray support

Can run in system tray with icon states, live tooltip, and a menu to start or stop the utility.

Live status & progress

A live countdown to the next click or spin, along with a total counter.

Taskbar icon progress

A progress bar on the taskbar icon that gradually depletes until the next click/spin.

Fits right into Windows

Fluent design

Build with WinUI with support for light, dark, or automatic theming.

Check for updates

Check manually from Settings, or let MouseUtil check automatically every time it starts.

Persisted config file

Your interval, hotkey, and all other settings are remembered the next time you open the app.

A couple of things to know

Fair warning
I'm not a software developer. This project was developed primarily using Claude Code, with me directing the architecture, reviewing the generated code, testing, and making iterative improvements. All code in this repository has been reviewed before release. The only asset not created with AI is the app icon, which I designed myself.
Unsigned installer
Ships as an unsigned .exe installer, so Windows SmartScreen may display a warning the first time you run it.
