MouseUtil / Features

Features

Windows 10/11 · Free & open source

One timer, two ways to use it

Auto click

Automatically clicks where the mouse pointer is, on the interval you set.

Spin mode

Moves the cursor in a tiny circle and lands back on the exact starting pixel.

Set your own interval

Custom interval

Set the timer between each click/spin and go.

Randomized interval

Vary the gap between actions instead of ticking on a metronome. Each interval lands somewhere in the range you set.

Advanced interval view

Need finer control? Switch to Hours / Minutes / Seconds / Milliseconds fields instead of just Minutes and Seconds.

Stays out of your way

Pause on manual movement

Touch the mouse yourself in Spin mode and MouseUtil steps back immediately, resuming on a fresh countdown once you let go.

Auto-stop conditions

Set a click/spin repeat limit or a stop date and time.

Global hotkey

Start or stop from anywhere with one keypress even while another window has focus. F6 by default.

See what it's doing

System tray support

Close the window and MouseUtil keeps running quietly in the tray instead of exiting. Icon states, a live tooltip, and a right-click menu to start or stop without opening the window.

Live status & progress

A running countdown like "Clicking in 32s," an action counter, and an optional progress bar mirrored onto the taskbar icon.

Fits right into Windows

Fluent design

Light, dark, or system theming, styled to feel native on Windows 11.

Check for updates

Check manually from Settings, or let MouseUtil check automatically every time it starts.

Persisted config file

Your interval, mode, hotkey, and every other preference is remembered the next time you open the app.

A couple of things to know

Fair warning
I'm not a software developer. This project was developed primarily using Claude Code, with me directing the architecture, reviewing the generated code, testing, and making iterative improvements. All code in this repository has been reviewed before release. The only asset not created with AI is the app icon, which I designed myself.
Unsigned installer
Ships as an unsigned .exe installer, so Windows SmartScreen may display a warning the first time you run it.
